tu.api.register_command(target, *, name=None, type=None, description=None, tags=None, aliases=None, depends_on=None, env=None, timeout=None, allow_dot_name=False)[source]¶

Register a new command.

Parameters:

  • target (str) – Target to execute (command, module, callable).

  • name (Optional[str]) – Command name (FQN). If None, inferred from target.

  • type (Optional[str]) – Command type (shell, python_module, python_callable). If None, inferred.

  • description (Optional[str]) – Optional description.

  • tags (Optional[list[str]]) – Optional list of tags.

  • aliases (Optional[list[str]]) – Optional list of alternative names.

  • depends_on (Optional[list[str]]) – Optional list of commands this depends on.

  • env (Optional[dict[str, str]]) – Optional environment variables to set.

  • timeout (Optional[int]) – Optional timeout in seconds.

  • allow_dot_name (bool) – Allow registering names with dots without confirmation.

Return type:

RegisteredCommand

Returns:

The registered RegisteredCommand.

Raises:

  • NameCollisionError – If the name already exists.

  • InvalidNameError – If the name is invalid.

  • old_name (str) – Current name of the command.

  • new_name (str) – New name for the command.

Raises:

  • UnknownCommandError – If the old command doesn’t exist.

tu.api.run(name, args=None, *, capture_output=False, dry_run=False, verbose=False, timeout_override=None, log_output=False, log_dir=None, track_history=True)[source]¶

Run a command.

Parameters:

  • name (str) – Command name to run.

  • args (Optional[list[str]]) – Arguments to pass to the command.

  • capture_output (bool) – Whether to capture stdout/stderr.

  • dry_run (bool) – If True, show what would execute without running.

  • verbose (bool) – If True, show detailed execution information.

  • timeout_override (Optional[int]) – Override the command’s timeout setting.

  • log_output (bool) – If True, write output to log file.

  • log_dir (Optional[Path]) – Optional directory for log files.

  • track_history (bool) – If True, add to command history.

Return type:

RunResult

Returns:

RunResult with execution results.

Raises:

  • UnknownCommandError – If the command is not found and not a dotted name.

  • CommandExecutionError – If execution fails.
